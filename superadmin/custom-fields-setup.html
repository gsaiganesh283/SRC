🔧 Custom Fields Setup Instructions

⚠️ Important Notice: The custom fields feature requires additional database tables. Follow the instructions below to enable this feature.

📋 Prerequisites

  • Access to phpMyAdmin or MySQL command line
  • Database credentials for your SR Colony system
  • The SQL file: database/CREATE_CUSTOM_FIELDS_TABLE.sql

🚀 Setup Steps

Step 1: Locate the SQL File

Navigate to your project directory and find:

database/CREATE_CUSTOM_FIELDS_TABLE.sql
Step 2: Access Your Database

Open phpMyAdmin or connect via MySQL command line:

mysql -u your_username -p your_database_name
Step 3: Run the SQL Script

Option A - Using phpMyAdmin:

  1. Open phpMyAdmin
  2. Select your database (srcolony)
  3. Click on "SQL" tab
  4. Copy the contents of CREATE_CUSTOM_FIELDS_TABLE.sql
  5. Paste into the SQL query box
  6. Click "Go" to execute

Option B - Using Command Line:

mysql -u your_username -p srcolony < database/CREATE_CUSTOM_FIELDS_TABLE.sql
Step 4: Verify Installation

Check that the following tables were created:

  • custom_field_definitions - Stores field definitions
  • custom_field_values - Stores field values

Run this query to verify:

SHOW TABLES LIKE 'custom_field%';
✅ Success! Once the tables are created, you can:
  • Import/Export custom field definitions
  • Import/Export custom field values
  • Extend member and transaction data with custom fields
  • View custom fields statistics on the dashboard

📊 What Gets Created

Table 1: custom_field_definitions

Defines the structure of custom fields:

  • Field Types: text, number, date, dropdown, checkbox, textarea, email, phone
  • Entity Types: member, transaction, year, general
  • Features: Validation rules, required fields, dropdown options
Table 2: custom_field_values

Stores actual values for custom fields:

  • Links to members, transactions, or years
  • Prevents duplicate values
  • Supports all field types
Sample Data Included:
  • Member Fields: Occupation, Blood Group, Emergency Contact, Annual Income, Joining Date, Notes
  • Transaction Fields: Payment Category, Approved By, Attachment URL
  • Pre-configured dropdown options for Blood Group and Payment Category

🔍 Troubleshooting

Error: "Table already exists"

The tables are already created. You can use the feature immediately.

Error: "Access denied"

Ensure you have CREATE and ALTER privileges on the database.

Error: "Syntax error"

Make sure you copied the entire SQL file without modifications.
