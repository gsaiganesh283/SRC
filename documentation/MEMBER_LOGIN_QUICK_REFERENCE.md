# Member Login - Quick Reference Card

## 🚀 Quick Start

### First Time Login
```
Username: Your 10-digit mobile number
Password: Your 10-digit mobile number (same)
```

**Example**:
- Phone: `6281718680`
- Username: `6281718680`
- Password: `6281718680`

After login → Change password immediately!

---

### Regular Login (After First Time)
```
Username: Your mobile number
Password: Your new password (that you set)
```

---

## 📋 Step-by-Step

### 🆕 First Time Login Process

1. **Go to**: Login page
2. **Enter**:
   - Mobile Number: `6281718680`
   - Password: `6281718680`
3. **Click**: "Login to Dashboard"
4. **You'll be redirected** to change password
5. **Enter**:
   - New Password: `[Your secure password]`
   - Confirm: `[Same password]`
6. **Click**: "Change Password"
7. **Done!** → Dashboard opens

### 🔄 Regular Login Process

1. **Go to**: Login page
2. **Enter**:
   - Mobile Number: `6281718680`
   - Password: `[Your password]`
3. **Click**: "Login to Dashboard"
4. **Done!** → Dashboard opens

## ⚠️ Common Errors

| Error | Solution |
|-------|----------|
| "Invalid mobile number or password" | Check your phone number and password are correct |
| "Use your mobile number as password" | First login: Use phone number as both username and password |
| "Please enter both fields" | Fill in both mobile number and password fields |

## 💡 Tips

✅ **First Login**: Phone number = Password  
✅ **Change Password**: Make it strong and unique  
✅ **Remember**: Write down your new password securely  
✅ **Security**: Don't share your password with anyone  
✅ **Logout**: Always logout when done  
✅ **Help**: Contact admin if you can't login

**Bad Passwords**:
